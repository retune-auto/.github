<h1 align="center">Retune</h1>

<p align="center">
  A touchscreen infotainment system for the 2006 to 2013 Lexus IS350, built on Chassis.
</p>

<p align="center">
  <img src="assets/gauges.png" width="720" alt="Retune's gauges: a tachometer with a red needle, speed, coolant and battery voltage">
</p>

- Gauges drawn for the car, with a start-up sweep like a factory self-test
- Fault codes explained in plain words
- Settings wait until you're parked; music and navigation never do

Releases: [retune-releases](https://github.com/retune-auto/retune-releases)
